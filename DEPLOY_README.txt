SURPRISESUITE MOMENT STUDIO — WEBSITE-READY V1

FILES (FLAT, NO FOLDERS INSIDE)
- index.html: Main website/app — required
- demo.html: Optional playable demo — remove if you do not want it public

OPTION A: GITHUB PAGES (FREE PUBLIC DEMO)
1. Sign in to github.com and create a NEW repository named surprisesuite-moment-studio.
2. Set visibility to Public (for GitHub Pages on GitHub Free).
3. Open the repo > Add file > Upload files. Upload index.html and optionally demo.html. Commit changes.
4. In repository Settings > Pages: Source 'Deploy from a branch', Branch 'main', Folder '/ (root)', then Save.
5. Once GitHub confirms publishing, open https://YOUR-GITHUB-USERNAME.github.io/surprisesuite-moment-studio/

OPTION B: USE YOUR EXISTING RENDER WORKSPACE
1. Upload files to a new GitHub repository as in steps 1–3 above.
2. In dashboard.render.com select New > Static Site; select the repository.
3. Branch: main; Build command: echo ready; Publish directory: .
4. Deploy. Render provides a public https://...onrender.com address.

OPTION C: FASTEST, NO GITHUB
1. Go to https://app.netlify.com/drop
2. Upload this ZIP (or drag the extracted flat folder).
3. Netlify provides a live https://...netlify.app URL. Claim your site to retain/manage it.

IMPORTANT: The website and client-side creator are public, but each person's uploaded files remain in their own browser unless they export and share an HTML show. The app does NOT store customer data on a central server, create customer-specific public QR links, handle payment, or automatically calibrate full 3D geometry. This is a public test/development app, not a secure commercial multi-customer platform. Do not add private customer photos or recordings to a public GitHub repo.
